# Tableau Airbnb Case Study

## 📊 Project Overview

This project is a Tableau-based analysis of Airbnb listings. The objective is to explore listing characteristics, pricing, room types, host information, neighbourhoods, and customer review performance through interactive visualizations.

## 🎯 Objectives

* Analyze Airbnb listing prices
* Compare different room types
* Explore listings across neighbourhoods and cities
* Analyze host characteristics
* Examine review scores and listing performance
* Identify patterns and insights from Airbnb listing data
* Build an interactive Tableau dashboard for data-driven analysis

## 🛠️ Tools & Technologies

* Tableau
* Microsoft Excel
* Data Visualization
* Exploratory Data Analysis

## 📂 Dataset

The dataset contains Airbnb listing information including:

* Listing ID
* Host information
* Host response and acceptance rates
* Superhost status
* Neighbourhood
* City
* Property type
* Room type
* Accommodates
* Bedrooms
* Price
* Minimum and maximum nights
* Review scores
* Instant bookability

## 📈 Dashboard

The Tableau dashboard provides interactive analysis of Airbnb listings using filters and visualizations to explore pricing, property characteristics, host information, and reviews.

## 🔍 Key Analysis Areas

### Listing Analysis

Analysis of Airbnb listings based on property type, room type, bedrooms, and capacity.

### Pricing Analysis

Comparison of listing prices across different property and room types.

### Host Analysis

Analysis of host characteristics including superhost status, response rate, acceptance rate, and verification.

### Review Analysis

Analysis of review scores including overall rating, cleanliness, accuracy, communication, check-in, location, and value.
